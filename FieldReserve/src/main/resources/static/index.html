System Structure

How the application is organized.

User chooses a field

The user checks available sports fields and selects a suitable option.

Reservation is created

The booking stores the user ID, field ID, date, start time, and end time.

Status is managed

The system tracks reservation status and payment status.

Data stays organized

Fields and locations are managed from separate pages for cleaner structure.
